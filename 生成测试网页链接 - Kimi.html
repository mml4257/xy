打开 HTML 文件很简单，常见方法有几种：
1. 双击打开（最简单） 直接把 .html 文件拖到浏览器窗口，或者右键 → 打开方式 → 选择 Chrome / Edge / 火狐等浏览器。HTML 本身就是给浏览器看的，不需要安装任何软件。
2. 从浏览器里打开
  • 按 Ctrl + O（Mac 是 Cmd + O），在弹出的窗口里选你的 HTML 文件
  • 或者把文件直接拖进已经打开的浏览器标签页
3. 手机上打开
  • 安卓：用文件管理器找到这个文件，点击后用浏览器打开
  • iPhone：可以存到「文件」App，点开后选用浏览器或 WPS 打开；也可以发到微信「文件传输助手」，点开后用浏览器打开
